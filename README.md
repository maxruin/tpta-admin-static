# 臺灣物理治療學會官網改版 — CMS 後台管理系統（示意介面）

純前端 Mockup，用於介面驗收與流程走查；無實際後端，所有「儲存／上傳」為模擬操作（Toast 提示），重新整理後不保留變更。視覺風格參考 [Sneat](https://themewagon.com/themes/free-responsive-bootstrap-5-html5-admin-template-sneat/)（淺色側邊欄＋陰影卡片＋Public Sans 字體），主色沿用前台識別色 `#2780AF`。

## 目錄結構

```
CMS/
├── login.html                CMS 登入頁（雙欄：品牌視覺 + 表單）
├── dashboard.html             儀表板
├── 課程管理-列表.html … 系統管理-角色權限管理.html   42 個後台管理頁面
├── css/
│   └── admin.css              後台共用樣式（側邊欄／表格／表單／Modal…）
├── js/
│   └── admin.js                共用互動（側邊欄、Tab、Modal、表格搜尋/排序/批次、
│                                上傳預覽、富文本工具列、表格式資料新增列…）
└── _build/
    ├── build.ps1               組建腳本：依模組資料表產生 frag → 套版 → 輸出到 CMS/*.html
    └── frag/                   各頁主體（不含共用側邊欄／頂欄）
```

## 操作慣例（全站統一）

- **刪除一律於列表頁進行**：以表格左側核取方塊多選＋頂部「批次刪除」，單則編輯／詳情頁不提供刪除按鈕。
- **單則編輯／詳情頁為單欄版面**：不放右側資訊區塊；必要的狀態／建立時間等資訊改以頁首下方一條「meta-strip」橫幅呈現。
- **不提供暫存草稿**：編輯頁僅一個「儲存變更」動作，無草稿/發布兩階段。
- **不含 SEO 設定**：全站無 SEO 相關欄位或頁面。
- **無全站搜尋／通知鈴鐺**：頂欄僅保留麵包屑與使用者選單；各列表頁仍有各自的欄內搜尋／篩選。

## 與前台頁面的對應關係

CMS 每個管理模組對應一個或多個 `../HTML/*.html` 前台頁面（例如「課程管理」對應
`01-01課程列表頁.html` ＋ `01-02課程單則頁.html`）。完整對應請參考 `_build/build.ps1`
中 `$SidebarGroups`（選單分組）與各模組資料表（`$ListEditModules`／`$ModalListModules`／
`$DetailListModules`／`$SingleModules`／`$TableDataModules`），或對照專案根目錄的
`網站地圖.xlsx`。

## 模組類型

- **列表＋編輯**（7 組）：課程、積分認定公告、學會公告、訊息轉知、衛教文章、臨床實習重點訊息、就業資訊。
- **純列表（Modal 快速新增）**（6 個）：學校連結、公會連結、常見問答、檔案下載、意見反映紀錄、帳號管理。
- **列表＋詳情**（3 組）：研討會投稿、入會審核、會員管理。
- **單頁內容維護**（7 個）：發展歷程、學會章程、願景與目標、理事長、祕書處、服務申辦專區、聯絡我們設定。
- **表格式資料維護**（3 個）：歷屆理監事會、理監事會、各委員會。
- **其他獨立頁**：儀表板、金流訂單、首頁 Banner 管理、選單管理、角色權限管理。

## 修改與重建

- **只改樣式**：編輯 `css/admin.css`，各頁即時套用。
- **改模組資料（欄位、假資料、新增/移除模組）**：編輯 `_build/build.ps1` 對應的模組資料表，
  然後執行：`powershell -ExecutionPolicy Bypass -File _build/build.ps1`

## 後續導入正式系統時的建議

1. 以本 Mockup 之欄位與流程作為後端 API／資料庫欄位設計依據。
2. 「列表＋編輯」型模組欄位高度相似，建議後端以單一「文章型內容」資料表＋分類欄位（對應舊站
   `articles.php?type=`）實作，前台以模組別過濾即可，降低重複開發成本。
3. 金流、會員審核、意見反映等流程涉及狀態機（待審核／已通過／已退回…），建議正式開發時另訂
   狀態轉換規則與通知信件（Email／簡訊）觸發時機。
